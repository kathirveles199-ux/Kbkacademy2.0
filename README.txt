KBK Academy — Approved Design Implementation Preview

START HERE
1. Extract this ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Use the Login / Join Now buttons to open student-dashboard.html.
4. Open course-learning.html from the student dashboard.
5. Open admin-dashboard.html directly to review the admin view.

WHAT THIS PACKAGE DOES
- Implements the approved Tamil-inspired KBK visual direction as four separate responsive HTML pages:
  1. Public homepage
  2. Student dashboard
  3. Course learning workspace
  4. Admin dashboard
- Reuses a crop of the approved image for the scenic homepage hero artwork.
- Includes CSS-only responsive layouts and small demonstration interactions.

IMPORTANT LIMITATION
This is a visual/local prototype, not yet wired to your production Supabase project.
Authentication, live lesson videos, PDF files, actual student metrics, and admin actions are demonstration placeholders. Do not replace your live repository files with this package until we map and preserve the existing Supabase/auth/RLS code. Google Fonts require internet access; the pages otherwise run locally.
